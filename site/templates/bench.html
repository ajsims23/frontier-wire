Method and limits

  • Every model gets the same instruction and document, and must answer in a fixed JSON format (structured output is part of the test: a model that can't return clean fields can't run in a pipeline).
  • The documents are synthetic, written for this bench in the formats {{ org.name }} teams handle. Every fund, company and person in them is fictional, so no client data ever reaches a free-tier model.
  • Only free models are tested, because that is what this agent runs on. Paid frontier models are tracked on the model tracker from public benchmarks.
  • The bench runs weekly and whenever the tasks change. A rate-limited request is retried once after a pause, so a busy free tier isn't counted against a model.
  • Twelve tasks are a signal, not a verdict: use the results to choose what to pilot, then test on your own (approved) documents.

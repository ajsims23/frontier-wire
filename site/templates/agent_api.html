Tools

  • search_newsSearch the fact-checked archive. Each result links to its story page (with sources) and carries the {{ org.name }} lens.
  • what_changedEverything since a date: new stories, radar moves, the latest calls for {{ org.name }}.
  • dpa_briefThis week's calls and the developments to act on, optionally for one role or capability.
  • get_radarThe AI Radar, filtered by ring, quadrant or capability, with evidence.
  • best_model_forTask bench results: which free model does extraction, quality checks, research or routing best.
  • ask_wireA cited answer to a question, written from the archive.
  • system_statusThe pipeline's numbers and the accuracy audit, so your agent knows how far to trust it.

Try asking your assistant: "Using Frontier Wire, which free model is best for table extraction right now, and how sure are you?" or "What should our extraction team test this week?"
